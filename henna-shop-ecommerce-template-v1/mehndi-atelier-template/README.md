# mehndi-atelier-template — source code

Live demo: https://kedhar-components.pages.dev/#mehndi-atelier-template

Folders under components/ are React + TypeScript + Tailwind components.
Main file: components/mehndi-atelier-template/mehndi-atelier-template.tsx  (usage example: components/mehndi-atelier-template/demo.tsx)

Put each folder's .tsx file at src/components/ui/<folder>.tsx in a
shadcn-style project (the code imports siblings as @/components/ui/<name>).

npm packages used: gsap, react
